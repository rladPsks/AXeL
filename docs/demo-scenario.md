# AXeL 시연 가이드

> 권장 시연: 2~3분  
> Live Demo: https://axel-axedu.vercel.app

## 시연 목표
**민원이 담임에게 바로 전달되지 않고, AXeL이 먼저 근거·이력·업무분장을 확인해 학교 대응계획을 만든다**는 것을 보여줍니다.

## 1. 생활지도 민원 접수
- 접수 경로: 유선전화
- 민원 종류: 생활지도 불만
- 관련자: 담임교사
- 발생 경위: 수업 중 생활지도 상황

> 우리 아이가 수업 시간에 다른 학생보다 자주 지적받는다고 합니다. 어떤 상황 때문에 지도가 이루어졌는지 확인해 주세요. 담임선생님과 바로 통화하고 싶습니다.

### 접수·AI 분류 화면에서 보여줄 것
1. **LLM 분류: LLM**
2. **RAG 공식 근거** — 문서명·페이지·본문
3. **업무분장** — 생활체육부장 / 담임 협조 / 교감 승인
4. **보호자 직접 연락: 현재 단계에서는 요청하지 않음**

발표 멘트:
> 담임이 사실을 가장 잘 안다는 이유로 민원 전체를 담임에게 넘기지 않습니다. Agent가 학교 업무분장을 먼저 확인하고 담임에게는 확인 가능한 사실만 요청합니다.

## 2. Fact Check
교사 업무 탭에서 실제 Task를 보여줍니다.

- 사건 총괄은 관리자에게 유지
- 수행자만 담당 교직원으로 지정
- 민원 전체가 아니라 필요한 사실 중심으로 질문

예시 회신:
> 10월 30일 수업 중 학생이 세 차례 자리에서 이탈해 해당 행동에 대한 생활지도가 이루어진 것으로 확인했습니다. 현재 확인된 범위에서는 특정 학생만 별도로 반복 지적한 사실은 확인되지 않았습니다.

## 3. Agent Re-planning
AI 지원 검토에서:
- FACT / CLAIM / UNVERIFIED
- 추가 확인 필요사항
- 지원 방향
- 보호자 답변 초안
- 사용 evidence
- Validator
- 사람 검토 대기

발표 멘트:
> Agent는 접수 때 한 번 실행되고 끝나지 않습니다. 사실확인 회신이 들어오면 기록과 공식 근거를 다시 읽고 대응계획과 답변을 재구성합니다.

## 4. History / 과잉이관 방지
같은 보호자·학생의 유사 민원에서:
- LINK_UNRESOLVED
- REVIEW_FOLLOW_UP
- REVIEW_REPEAT

중 하나를 제안합니다.

강조:
> 민원 횟수나 감정 표현만으로 반복·악성 민원 또는 교육지원청 이관을 확정하지 않습니다. 이전 답변 완료 여부, 새 사실, 미이행 업무와 공식 근거를 함께 확인합니다.
